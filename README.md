# 强迫症助手

macOS 菜单栏工具，自动检测长时间未使用的应用并提醒关闭。

## 功能

- **空闲检测**：实时监控应用活跃状态，超过阈值未使用则弹出提醒
- **通知面板**：右上角弹出悬浮窗，显示所有空闲应用，一键退出或保留
- **排除列表**：可排除不需要监控的应用（菜单中「排除此应用」）
- **锁屏/休眠感知**：锁屏或休眠时暂停计时，唤醒后自动重置
- **开机启动**：支持随系统自动启动
- **零打扰**：前台正在使用的应用不会被误判为空闲
- **媒体播放器保护**：后台播放中的 Apple Music、Spotify、QQ 音乐等不会被建议退出
- **系统应用保护**：Finder、loginwindow 等系统关键应用永不建议退出

## 系统要求

- macOS 15.0+
- Intel 或 Apple Silicon

## 安装

### 从源码构建

```bash
# 构建当前架构
make $(uname -m)
make install

# 或构建双架构
make all
```

构建产物为未签名 `.app`，安装到 `/Applications/QPHelper.app`。

### 卸载

```bash
make uninstall
```

## 使用

1. 首次启动后，状态栏会出现图标
2. 点击图标展开菜单，查看当前被监控的应用及其空闲时长
3. 当有应用超过空闲阈值（默认 60 分钟），右上角弹出通知面板
4. 在通知面板中点击「退出」关闭应用，点击「保留」重置计时
5. 通过菜单中的「空闲阈值」调整提醒时间
